\begin{question}
    David Chen, a financial advisor, promotes a new investment fund on social media, claiming it offers high returns with minimal risk. The fund primarily invests in volatile tech startups. Chen assures potential investors that the fund is a safe and lucrative option. Which of the following statements is most correct regarding Chen’s actions?\\
    大卫·陈，一位金融顾问，在社交媒体上推广一个新的投资基金，声称该基金提供高回报且风险较低。该基金主要投资于波动性较大的科技初创公司。陈向潜在投资者保证该基金是一个安全且有利可图的投资选项。哪一项陈述最正确地描述了陈的行为？
\end{question}

\begin{choices}
    \item Chen did not violate the GARP Code of Conduct because investment funds are generally considered safe.\\
    陈没有违反GARP行为准则，因为投资基金通常被认为是一种安全的投资。
    \item Chen violated the part of the GARP Code of Conduct dealing with confidentiality.\\
    陈违反了GARP行为准则中关于保密的部分。
    \item Chen violated the GARP Code of Conduct by misrepresenting the fund's risks and not providing a clear explanation of potential volatility.\\
    陈通过歪曲基金的风险并未能提供明确的潜在波动性解释，违反了GARP行为准则。
    \item Chen has not violated any of the ethical responsibilities related to the GARP Code of Conduct.\\
    陈没有违反与GARP行为准则相关的任何道德责任。
\end{choices}

\begin{correctanswer}
C
\end{correctanswer}

\begin{explanation}
    \textbf{C选项正确。}
    \begin{itemize}
   \item Chen违反了行为准则中的职业操守和道德操守部分，错误地将基金表述为安全且有利可图的投资，而事实上该基金主要投资于波动性较大的科技初创公司。Chen没有解释基金的潜在风险，向投资者保证基金是安全的，歪曲了事实。根据准则，GARP成员不得故意歪曲与分析、建议、行动或其他专业活动有关的细节。
    \end{itemize}
\end{explanation}

\checklist{GARP行为准则。（职业操守和道德操守）}


\begin{question}
    Alex Johnson, FRM, has been managing a balanced portfolio for his clients using a strategy focused on stable dividend-paying stocks. Due to recent market shifts, Johnson decides to switch to a growth strategy targeting high-tech startups. Johnson will violate the GARP Code of Conduct if he makes this change in his investment process without:\\
    亚历克斯·约翰逊，FRM，一直使用专注于稳定分红股票的投资策略为客户管理平衡投资组合。由于最近的市场变化，约翰逊决定切换到增长策略，瞄准高科技初创公司。如果约翰逊在投资过程中做出这种改变，而未事先通知其主管，他将违反GARP行为准则。
\end{question}

\begin{choices}
    \item informing his supervisor before implementing the change.\\
    在实施改变之前通知其主管。
    \item promptly notifying his clients of the change in strategy.
    \item obtaining written consent from his clients prior to the change.\\
    在改变之前获得其客户的书面同意。
    \item receiving prompt written acknowledgment of the change from his clients within a reasonable time after the change.\\
    在改变后合理时间内收到其客户的书面确认。
\end{choices}

\begin{correctanswer}
B
\end{correctanswer}

\begin{explanation}
    \textbf{B选项正确。}
    \begin{itemize}
    \item Johnson改变投资策略而未及时告知其客户，这违反了GARP成员应充分、公平地披露所有可能会损害独立性和客观性，或干扰其对雇主、客户和潜在客户各事项的原则。
    \end{itemize}
\end{explanation}

\begin{question}
     Lisa Brown recommends investing in a real estate fund that focuses on commercial properties. She makes the following statements to her clients: \\
     I. The properties are insured, so the risk of loss due to damage is minimal.\\
    II. Investing in this fund will guarantee you a 12\% annual return based on past market trends.\\
    Lisa Brown建议投资一只专注于商业地产的房地产基金。她向客户做出以下陈述： \\
    I. 这些物业已投保，因此因损坏而造成的损失风险很小。\\
   II. 根据过去的市场趋势，投资该基金将保证您获得12\%的年收益率。\\

\end{question}

\begin{choices}
    \item Neither statement violated the Code and Standards.\\
   两项陈述均未违反职业道德准则和标准。
    \item Only statement I violated the Code and Standards.\\
    只有陈述I违反了职业道德准则和标准。
    \item Only statement II violated the Code and Standards.\\
    只有陈述II违反了职业道德准则和标准。
    \item Both statements violated the Code and Standards.\\
    两项陈述均违反了职业道德准则和标准。
\end{choices}

\begin{correctanswer}
C
\end{correctanswer}

\begin{explanation}
    \textbf{C选项正确。}
    \begin{itemize}
    \item I．“物业投保，因此因损坏而导致的损失风险很小。”这是对保险的客观事实陈述，没有违反行为准则。
    \item II．“投资该基金将保证您根据过去的市场趋势获得12\%的年回报率。”保证特定的回报率是一种观点而非客观事实的陈述，因此是一种虚假陈述，违反了行为准则。
    \end{itemize}
\end{explanation}

\checklist{GARP行为准则。（事实与意见的区分）}

Carter implements a compliance framework based on outdated regulations that have been revised in recent years. Neither Carter nor her team is aware of these regulatory updates. As a GARP member, has Emily violated the GARP Code of Conduct?\\
    艾米丽·卡特被任命为XYZ投资公司的合规主管，这是一家位于加拿大的精品公司。卡特实施了一个基于已过时的法规的合规框架，这些法规在近年来已被修订。Carter和她的团队都不知道这些法规的更新。作为GARP会员，艾米丽是否违反了GARP行为准则？
\end{question}

\begin{choices}
    \item No, this is not a violation of the GARP Code of Conduct because neither Carter nor her team is aware of the regulatory updates.\\
    不，这不是GARP行为准则的违反，因为Carter和她的团队都不知道这些法规的更新。
    \item No, this is not a violation because the framework was valid when Carter completed her compliance certification.\\
    不，这不是GARP行为准则的违反，因为框架在Carter完成合规认证时是有效的。
    \item This is only a violation of the GARP Code of Conduct if compliance decisions are made based on Carter’s outdated framework.\\
    只有当合规决定基于Carter的过时框架时，才违反GARP行为准则。
    \item Yes, this is a violation of the GARP Code of Conduct.\\

D
\end{correctanswer}

\begin{explanation}
    \textbf{D选项正确。}
    \begin{itemize}
    \item Emily Carter实施的合规框架基于已过时的法规，这些法规在近年来已被修订。Carter和她的团队都不知道这些法规的更新。这违反了行为准则，GARP行为准则规定，GARP成员应熟悉当前普遍接受的合规实践。
    \end{itemize}
\end{explanation}

\begin{question}
    As the Chief Risk Officer of a major bank, Ms. Li is responsible for evaluating new counterparty risk models. A well-known consulting firm offers her a one-week high-end training program in Dubai (valued at 80,000 RMB, including airfare, accommodation, and all activity expenses) in hopes that she will consider adopting their newly developed model. According to regulatory professional ethics guidelines, how should she handle this invitation?\\
    作为一家大型银行的首席风险官，李女士负责评估新的对手方风险模型。一家知名的咨询公司向她提供了一个在迪拜一周的高端培训计划（价值80,000人民币，包括机票、住宿和所有活动费用），希望她考虑采用他们新开发的模型。根据监管专业道德准则，她应该如何处理这份邀请？
\end{question}
    
    \begin{choices}
        \item She can accept the training invitation as long as she fully discloses all details to the board of directors.\\
        她可以接受培训邀请，只要她完全向董事会披露所有细节。
        \item She should politely decline the invitation and report this incident to the compliance department.\\
        她应该礼貌地拒绝邀请，并报告此事合规部门。
        \item She can accept the invitation without reporting it, as this is a common practice in the industry.\\
        她可以接受邀请而不报告，因为这是行业中的常见做法。
        \item She can accept just the airfare portion of the offer (valued at 15,000 RMB) while declining other expenses, as this represents a smaller value that is less likely to influence her judgment.\\
        她可以接受机票部分（价值15,000人民币），同时拒绝其他费用，因为这代表一个较小的价值，不太可能影响她的判断。
    \end{choices}
    
    \begin{correctanswer}
    B
    \end{correctanswer}
    
    \begin{explanation}
        \textbf{A选项错误。}
        \begin{itemize}
            \item 即使向董事会披露，高额培训邀请仍可能影响决策的独立性和客观性，披露行为并不能消除利益冲突本身，也不能完全消除其对判断的影响。
        \end{itemize}
        
        \textbf{B选项正确。}
        \begin{itemize}
            \item 拒绝邀请并报告合规部门完全符合监管要求的两个核心原则：独立性和透明度，这种做法不仅保护了个人，也维护了机构的声誉和整体利益。
        \end{itemize}
        
        \textbf{C选项错误。}
        \begin{itemize}
            \item "行业普遍做法"这一理由本身就反映了对职业道德认识的偏差，不报告行为进一步加重了违规性质，违背了金融监管的基本要求。
        \end{itemize}
        
        \textbf{D选项错误。}
        \begin{itemize}
            \item 无论金额大小，只要是与业务决策相关的利益，都属于不当利益,将利益拆分或降低金额的做法本质上仍然违反了独立性原则。
        \end{itemize}
    \end{explanation}
    
    \checklist{职业道德准则（不要做影响独立性和客观性的事情）}



    \begin{question}
        Sarah, a newly certified GARP member working as a risk manager at a multinational financial institution, is attending a new employee training session. During the discussion about GARP's Code of Conduct, which of the following statements correctly reflects the professional ethics requirements?\\
        莎拉，一位新认证的GARP会员，在一家跨国金融机构担任风险经理。她参加了一个新员工培训课程。在关于GARP行为准则的讨论中，哪一项陈述正确反映了专业道德要求？
    \end{question}
    
    \begin{choices}
        \item When facing conflicts between GARP's Code of Conduct and local regulations, members should prioritize the Code of Conduct to maintain professional standards.\\
        当面对GARP行为准则和当地法规之间的冲突时，会员应优先考虑行为准则以维护专业标准。
    
        \item Members should continuously enhance their professional knowledge, but there is no obligation to inform clients about their expertise limitations in specific areas.\\
        会员应不断增强专业知识，但不必告知客户他们在特定领域的专业能力限制。
    
        \item In situations where professional standards conflict with local customs, members should adhere to whichever standard sets a higher ethical bar.\\
        当专业标准与当地习俗发生冲突时，会员应遵守最高道德标准。
    
        \item To improve work efficiency, members can delegate their core professional responsibilities to qualified team members under proper supervision.\\
        为了提高工作效率，会员可以将核心专业职责委托给合格的团队成员，在适当的监督下。
    \end{choices}
    
    \begin{correctanswer}
    C
    \end{correctanswer}
    
    \begin{explanation}
        \textbf{A选项错误。}
        \begin{itemize}
            \item GARP会员必须同时遵守法律法规和职业道德准则，将协会准则置于法律之上的说法是错误的，这违背了合规的基本原则和风险管理的根本要求。
        \end{itemize}
        
        \textbf{B选项错误。}
        \begin{itemize}
            \item GARP会员确实需要持续学习以保持专业水平，但必须向客户准确披露自己专业能力的局限性，这是职业道德中透明度和诚信的基本要求。
        \end{itemize}
        
        \textbf{C选项正确。}
        \begin{itemize}
            \item 当道德准则与当地文化习俗发生冲突时，应该选择采用更高标准的规则，这确保了职业道德的最高标准得到维护，体现了GARP对专业操守的严格要求。
        \end{itemize}
        
        \textbf{D选项错误。}
        \begin{itemize}
            \item GARP会员必须对自己的核心职责负责，不能将主要专业职责委托给他人，这关系到个人专业责任的承担，虽然可以进行团队协作，但不能转移核心责任。
        \end{itemize}
    \end{explanation}
    
    \checklist{GARP 的道德准则。（在道德准则和当地文化习俗产生矛盾和利益冲突时，GARP 会员应该遵守更高标准的规则）}


    \begin{question}
        John, a certified FRM holder, was found to have misrepresented his client's investment performance and violated GARP's Code of Conduct. The Ethics Committee is now reviewing potential disciplinary actions. Which of the following penalties falls within GARP's authority to impose?\\
        约翰，一位认证的FRM持有者，被发现对他的客户的投资业绩进行了虚假陈述，违反了GARP的行为准则。伦理委员会现在正在审查可能的纪律处分。哪一项惩罚属于GARP的权限？
    \end{question}
    
    \begin{choices}
        \item GARP can temporarily suspend or permanently revoke John's membership and his right to use the FRM designation.\\
        GARP可以暂时或永久取消约翰的会员资格，并撤销他使用FRM称号的权利。
    
        \item GARP will refer the case to local regulatory authorities who will determine appropriate legal sanctions.\\
        GARP将案件转交给当地监管机构，由他们决定适当的法律制裁。
    
        \item GARP will coordinate with local supervisory bodies to impose regulatory penalties on John.\\
        GARP将与当地监管机构协调，对约翰实施监管处罚。
    
        \item GARP will recommend that John's employer take disciplinary actions, including demotion and salary reduction.\\
        GARP将建议约翰的雇主采取纪律处分，包括降职和减薪。
    \end{choices}

    \begin{correctanswer}
    A
    \end{correctanswer}
    
    \begin{explanation}
        \textbf{A选项正确。}
        \begin{itemize}
            \item GARP有权对违反道德准则的会员采取纪律处分，包括暂时或永久取消会员资格，以及撤销使用FRM专业称号的权利。这是GARP维护职业道德标准的核心权力。
        \end{itemize}
        
        \textbf{B选项错误。}
        \begin{itemize}
            \item 法律制裁不在GARP的权限范围内，这属于司法机构的职权范围。虽然GARP可能会配合法律调查，但无权决定或影响法律处罚。
        \end{itemize}
        
        \textbf{C选项错误。}
        \begin{itemize}
            \item 监管处罚完全属于监管机构的职权范围。GARP作为专业资格认证机构，无权指导或影响监管机构的决定和处罚措施。
        \end{itemize}
        
        \textbf{D选项错误。}
        \begin{itemize}
            \item 雇主的人事处分，如降职降薪等，属于雇主的管理权限。GARP无权干预或建议雇主如何处理其内部人事问题。
        \end{itemize}
    \end{explanation}
    
    \checklist{GARP协会对于会员的惩罚措施。（对于违反道德准则的会员，GARP协会有权暂时或永久移除违规者的会员资格，也有权暂时或永久移除违规者使用FRM称号的权利。）}




    \begin{question}
        A certified FRM working as a risk manager at a bank is asked by the CRO to present a report to the public on the bank's compliance with industry best practices in risk management. The risk manager includes information about risk-adjusted returns of specific clients in the report to support the conclusion that the bank's risk management practices are strong. Which of the following statements is most appropriate regarding the adherence of the manager's behavior to the standards of the GARP Code of Conduct in this situation?\\
        一位认证的FRM在一家银行担任风险经理，被CRO要求向公众提交一份报告，报告银行在风险管理行业最佳实践方面的合规情况。风险经理在报告中包括了特定客户的风险调整回报信息，以支持银行风险管理实践强大的结论。在这情况下，关于经理行为对GARP行为准则标准的遵守，哪一项陈述最合适？
        
        \end{question}
        
        \begin{choices}
            \item  The manager violates the GARP Code of Conduct because the manager discloses some of the bank's confidential information.\\
            经理违反GARP行为准则，因为经理披露了银行的一些机密信息。
            \item The manager violates the GARP Code of Conduct because the manager overstates the strength of the bank's risk management practices in the report.\\
            经理违反GARP行为准则，因为经理夸大了银行风险管理实践的强度。
            \item The manager violates the GARP Code of Conduct because the manager does not distinguish between facts and opinions.\\
            经理违反GARP行为准则，因为经理没有区分事实和意见。
            \item The manager does not violate the GARP Code of Conduct.\\
            经理没有违反GARP行为准则。
        \end{choices}
        
        \begin{correctanswer}
        A
        \end{correctanswer}
        
        \begin{explanation}
            \textbf{A选项正确。}
            \begin{itemize}
                \item 经理在报告中披露了一些机密信息，即实现的损失回收率。根据GARP的规定，成员应采取一切合理的预防措施，以防止机密信息的故意和无意披露。披露这些信息可能会对银行的声誉和客户信任造成负面影响，因此违反了GARP的行为准则。
